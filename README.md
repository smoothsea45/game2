# 한성가록 · 한성과 양주

1600년 한성의 종이 공방을 운영하는 실시간 3D 웹게임입니다. 가주, 도제, 짐꾼에게 동시에 지시를 내리고 경쟁 지물전의 납품 시기를 보며 한지를 거래합니다.

가로 화면에서는 한성 거리가 창 전체에 펼쳐집니다. 거리의 인물이나 왼쪽 아래 초상화를 누르면 인물 옆에 명령이 뜹니다. 건물의 지붕이나 표찰을 누르면 소유 가문, 그 장소에 보관한 물품, 현장에 있거나 오는 인물을 볼 수 있습니다. 건물 창의 **보내기**로 선택한 인물을 이동시킵니다. 길을 누르거나 건물을 마우스 오른쪽 버튼으로 누르면 곧바로 걷습니다.

## 첫 거래

1. 도제를 선택하고 **한 번 뜨기**를 누릅니다.
2. 짐꾼에게 **한지 운송**을 지시합니다. 종이가 아직 완성되지 않았으면 공방에서 기다립니다.
3. 가주를 선택해 **종로 시전**으로 보냅니다. 가주와 짐이 모두 도착하면 시세를 확인하고 **한지 판매**를 누릅니다.

게임 안에서 일시정지와 1·2·4배속을 전환할 수 있습니다. 진행 상황은 플레이한 브라우저에 저장됩니다. 수량, 거래 단위, 인물과 점포는 게임을 위해 설정했습니다.

## 한지 최대 생산과 닥 매입

분이의 **최대 생산**은 지시할 때 공방에 있는 닥을 기준으로 작업 횟수를 정합니다. 닥 3묶음이 있으면 세 차례에 걸쳐 한지 12장을 뜹니다. 중간에 도착한 재료는 다음 지시에 쓸 수 있습니다.

윤서진을 **종로 시전**으로 보내 **시전에서 닥 매입**을 누릅니다. 곡식 5말로 산 닥 3묶음은 시전 인수대에 남습니다. 돌석에게 **닥 인수·운송**을 지시하면 장터에서 실제로 짊어지고 돌아오며, 공방에 내린 뒤에 생산할 수 있습니다. 재고 장부에서 시전 보관분과 운송 중인 짐을 확인합니다.

## 공방 운영과 가주 일정

**공방 → 위임 시작**을 누르면 분이와 돌석이 생산·운송·판매를 맡습니다. **5말 맡기기**로 공방 예산을 배정하면 닥이 부족해질 때 돌석이 종로에서 사 옵니다. 재료와 예산이 부족하면 공방 장부에 사유가 표시됩니다. 판매 대금은 가문 곡식에 들어갑니다.

**일정 → 두 약속 열기**를 누르면 양주 빈터 매입과 종로 서책상 면담의 접수 시간이 정해집니다. 가주를 원하는 장소로 보내고 일정에서 현장 접수를 신청합니다. 가주가 먼저 12말을 내고 빈터를 사면 보유한 하루마다 사용료 4말을 받습니다. 서책상을 만나면 이후 종로에서 판매하는 한지 한 장에 1말을 더 받습니다. 경쟁 상인 박만길도 직접 양주로 가서 자기 돈으로 매입할 수 있습니다. 접수가 끝나면 일정에서 같은 출발 시점의 다른 선택을 체험하고 본편으로 돌아올 수 있습니다.

## 한성과 양주 왕복

분이에게 **한 번 뜨기**, 돌석에게 **한지 운송**을 지시한 뒤 가주의 이동 목적지에서 **양주 장터**를 골라 **보내기**를 누릅니다. 먼 곳으로 보내면 시점이 인물을 따라갑니다. **시점 → 한성**을 누르면 가주의 이동이 계속되는 동안 공방을 볼 수 있습니다. 돌아올 때는 가주를 선택해 **본가**로 보냅니다.

**재고**에서 작업에 배정한 닥과 공방 선반, 돌석의 등짐, 시전 판매대에 놓인 한지를 각각 확인할 수 있습니다. **명령 중단**으로 생산을 멈추면 닥이 공방에 돌아갑니다. 운송을 멈춘 뒤 **한지 운송 재개**를 누르면 돌석이 지닌 짐을 그대로 배달합니다.

이전 버전의 저장 내용은 같은 브라우저와 같은 사이트 주소에서 이어집니다. 다른 탭에 새 기록이 생기면 오래된 탭의 진행이 멈춥니다. 해당 탭의 안내에서 최신 기록을 다시 열 수 있습니다. 창을 닫은 동안은 게임 시간이 멈추며, 다시 열면 저장된 길과 작업을 이어갑니다.

## 실행

정적 파일을 제공하는 웹 서버에서 저장소 루트의 `index.html`을 엽니다. 별도 빌드가 필요하지 않습니다. 예를 들어 저장소에서 `python3 -m http.server 8080`을 실행한 뒤 브라우저로 `http://localhost:8080`에 접속합니다. GitHub Pages에서는 `main` 브랜치의 루트를 배포 대상으로 선택합니다.

3D 그래픽은 저장소에 포함된 Three.js를 사용합니다. 라이선스는 [vendor/three-LICENSE.txt](vendor/three-LICENSE.txt)에 있습니다.
